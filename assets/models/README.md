# Modèles 3D (engins, personnages, mobilier)

Dépose ici les modèles au format **glTF binaire (`.glb`)**, puis déclare-les dans `../CREDITS.md`.

## Critères pour un modèle

| Critère | Exigence |
|---|---|
| Licence | CC0, CC-BY (auteur cité), ou achat avec droit d'utilisation dans un jeu. Jamais un modèle extrait d'un autre jeu. |
| Format | `.glb`, matériaux PBR (metallic/roughness), textures embarquées de 2048 px maximum |
| Poids | moins de 50 000 à 80 000 triangles par engin, moins de 15 000 par personnage |
| Échelle | 1 unité = 1 mètre, roues posées sur y = 0, avant de l'engin vers +x |
| Pièces séparées | échelle du PA ou du BEA (tourelle, bras, plans), rideaux de coffres, portes, gyrophares, pour pouvoir les animer |

## Engins prioritaires (SDIS 33)

- FPT (6 sapeurs-pompiers), FPTL (4)
- PA 18, PA 32 (2), BEA
- VSAV (3)
- VLCG (chef de groupe), VLCC (chef de colonne), VPC (poste de commandement)

## Nommage

`fpt.glb`, `fptl.glb`, `pa18.glb`, `pa32.glb`, `bea.glb`, `vsav.glb`, `vlcg.glb`, `sapeur-pompier.glb`

Les modèles peuvent aussi rester sur Sketchfab ou ailleurs : envoie le lien, je vérifie la licence, le nombre de triangles et le découpage avant intégration.
